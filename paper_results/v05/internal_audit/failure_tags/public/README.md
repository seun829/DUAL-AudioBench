# Failure-tag audit instructions

1. Open `author_01_failure_tag_booklet.md`.
2. Complete all 21 rows in `author_01_failure_tag_responses.csv`.
3. Select every supported tag, separated by semicolons; use `NONE` when no tag
   is supported.
4. Cite trace evidence and rate confidence from 1 to 5.
5. Do not open any `private/` directory until all ratings are saved.

This is a one-author internal audit of automatic diagnostic tags.
